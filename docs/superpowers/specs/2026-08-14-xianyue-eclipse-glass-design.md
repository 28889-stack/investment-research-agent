# 弦月研究「月蚀玻璃」视觉升级规格

## 目标

在不改变现有两页结构、API、任务轮询、研究工作流和独立报告页的前提下，将“弦月研究”应用页升级为深色、透明、具备克制环境动态的视觉系统。

该规格是 `2026-08-14-xianyue-research-frontend-design.md` 的视觉补充。产品名称、信息架构和功能边界保持不变。

## 视觉定位

命名为“月蚀玻璃”。它不复刻 Kimi 的图形、布局或动效；设计识别仍来自弦月研究的“弦波切口”，并将其表现为月蚀唱片与价格曲线的结合。

- 基底：近黑 `#07080B`；
- 强调：低饱和钴蓝与紫色光场；
- 文本：冷白、分级灰度；
- 表面：半透明深色背景、低对比白色细边框、有限的背景模糊；
- 圆角保持克制，避免泛化的玻璃卡片墙；
- 正文、表格和复杂任务信息使用更高不透明度，优先保证阅读与状态辨识。

## 页面一：标的选择

- 页面底层使用固定的深色环境光场与稀疏网格；
- 主视觉“弦波切口”变为低速旋转的月蚀唱片，内部价格线只进行极轻微的呼吸变化；
- 鼠标 Spotlight 仅在精细指针设备启用，范围受限且不会覆盖关键文本；
- 研究类型切换采用一次性的边缘流光提示，不持续循环；
- 表单与最近研究记录置于透明深色层中，输入区域保持高对比、明确焦点；
- 提交按钮拥有一次短暂扫光反馈，加载时保留真实文字状态。

## 页面二：研究过程

- 导航、研究概览、研究轨道、当前工作和记录区域采用分层透明深色表面；
- 总进度以钴蓝细线表现；
- 执行中节点显示短距离流光与呼吸边框；已完成、待执行、失败、取消和人工复核同时以文字、边框与色彩区分；
- Business/Industry 保持双线研究视觉，但不宣称后端并发执行；
- 数字进度在实际值变化时平滑递增，不伪造进度；
- 事件表、Agent 摘要和长文本区域不使用持续动画，避免干扰阅读。

## 动效系统

借鉴组件库的视觉语言，但不引入其 React、Tailwind 或动画依赖：

- 从 Aceternity UI 借鉴局部 Spotlight 与背景光束的层次控制；
- 从 Magic UI 借鉴边缘流光与网格质感；
- 从 Motion UI 借鉴真实状态变化的数字、加载器和按钮反馈。

实现限制：

- 不使用 WebGL、Canvas 粒子、第三方动画库或外部 CDN；
- CSS 负责背景光场、旋转、流光与过渡；
- JavaScript 只处理鼠标 Spotlight 坐标、真实进度数字的插值与状态切换；
- 单次交互动画时长控制在 160–520ms，环境动画周期不低于 12 秒；
- 所有动态均服从 `prefers-reduced-motion: reduce`；
- 无 `backdrop-filter` 支持时，透明层回退为更高不透明度的深色表面；
- 在触控设备上禁用鼠标 Spotlight。

## 组件与样式边界

新增或调整的样式仅命名空间化作用于 `.app-page`：

- `ambient-field`：深色环境光与稀疏网格；
- `glass-surface`：透明表面与无模糊降级；
- `cursor-spotlight`：桌面指针局部光；
- `border-beam`：一次性边缘流光；
- `number-ticker`：真实进度变更插值；
- `node-flow`：执行节点流光。

不改变 `.report-body` 的独立报告视觉系统。

## 验收标准

- 两个应用页均为深色透明视觉，独立报告页不被污染；
- 鼠标 Spotlight 只在桌面精细指针设备生效；
- 当前任务节点、实际进度和按钮操作存在可感知但克制的动态反馈；
- 非执行中的表格与阅读区不发生持续运动；
- `prefers-reduced-motion` 关闭所有非必要动态；
- 无 `backdrop-filter` 时应用仍可读、可操作；
- 现有页面测试、完整 Python 测试、Bridge 测试及构建继续通过。
