# 技术面基准行情图与形态解释图设计

## 目标

每一份技术面报告必须生成一张行情全景图，不以是否识别到技术形态为前提。对实际识别到的每一个形态，再生成一张遵循同一视觉骨架的专属解释图。

所有图继续使用内嵌 Canvas/JavaScript，导出后的单文件 HTML 不依赖 PNG、SVG、CDN 或网络。

## 图表层级

### 1. 强制基准行情图

固定放在“趋势分析”之后，具有 `technical-market-overview` 的固定图表 ID。

上半区展示：

- 收盘价；
- SMA5、SMA20、SMA60；
- 20 日支撑、60 日支撑；
- 20 日阻力、60 日阻力。

下半区展示：

- 每日成交量柱；
- 20 日成交量均线。

图表使用统一时间轴、价格轴和成交量轴，并提供网格、图例、日期刻度和来源说明。支撑与阻力使用可区分的虚线。默认展示最近 120 个交易日。

### 2. 逐形态解释图

只为 `TechnicalIndicators.signals` 中实际识别的形态生成，放在“技术形态候选”中对应的形态说明之后。

各形态图保留基准图的价格、均线、支撑阻力和成交量结构，再添加当前形态的定向标注：

- 价格趋势类：在价格区标记突破、跌破或均线排列发生位置；
- MACD 类：保留价格与成交量区域，并增加 MACD 指标区域和金叉/死叉标记；
- RSI 类：保留价格与成交量区域，并增加 RSI 指标区域、30/70 阈值和超买/超卖标记；
- 量价类：突出触发日成交量、收盘价方向和 20 日均量参照。

每张图下方继续显示“触发、确认、失效”文字规则。未识别形态时，不生成形态解释图，也不影响基准行情图和报告正文。

## 数据与权限

图表数据只来自当前技术面 run 的：

- `market_data.csv`；
- `technical_indicators.json`；
- 由 `indicators.py` 得出的扩展行情列。

不读取研究文字，不引入 Evidence、Assumption 或模型预测作为精确图表数据。图表生成失败时：

- 基准行情图失败应使技术报告校验失败；
- 单个形态解释图失败只跳过该图，报告仍可继续生成，并保留形态文字说明。

## 实现边界

- 扩展 `ChartSpec`/技术可视化数据以显式标记基准行情图和图表分区；
- 升级 Canvas runtime，支持价格主区、指标可选区、成交量副图区及共享横轴；
- 保持现有 `technical_report.html` 单文件导出与报告验证；
- 删除旧 PNG 技术图的残留依赖，不恢复 matplotlib 输出。

## 验收标准

- 无任何 `PatternSignal` 的技术任务仍生成一张行情全景图；
- 行情全景图包含价格、SMA5/20/60、20/60 日支撑阻力、成交量柱和 20 日均量；
- 每个实际识别形态生成一张专属解释图，且具有相同的价格—成交量骨架；
- MACD、RSI 图具有相应的指标区域与阈值/交叉标注；
- 图表在导出的离线 HTML 中可显示；
- 现有技术面权威数据边界、报告安全约束和全量测试保持有效。
