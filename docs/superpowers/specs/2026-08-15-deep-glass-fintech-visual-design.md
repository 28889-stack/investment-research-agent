# 深空金融玻璃前端视觉设计

## 目标与边界

将“弦月研究”的两个应用页面升级为深色、透明、具备金融科技产品质感的 AI 研究工作台。

本次只修改静态页面的表现层：`app/static/styles.css` 及必要的无语义装饰 class。不得修改 API 调用、事件处理、任务轮询、报告链接、页面文案、后端工作流或报告内容。

页面继续使用原生 HTML、CSS 和 JavaScript，不引入 React、Tailwind、第三方组件库、远程字体、CDN 或运行时依赖。

## 视觉方向

视觉锚点为“深空金融玻璃”，不是霓虹赛博终端：

- 背景使用近黑海军蓝，叠加低对比度的蓝紫极光与精细网格；
- 容器是低透明度深色玻璃，使用细边框、内高光和轻柔阴影建立层次；
- 交互主色为冰蓝，紫色只用于环境氛围，不用作第二套业务状态色；
- 字体使用现有系统字体栈与等宽数字，避免加载外部字体；
- 状态仍以现有成功、警告、失败语义区分，色彩压低饱和度。

设计参考采用 Aceternity 一类组件库的背景光束、渐变边缘、Bento 分区和微动效语言，但不复制其组件代码或页面结构。

## 页面结构

### 标的选择页

- 顶部导航改为悬浮深色玻璃条，品牌标记增加极细高光；
- 主区保留左侧研究类型与右侧任务表单，使用不对称 Bento 关系强化“研究入口”与“任务参数”的层级；
- 信号圆盘、工作流预览与表单作为同一深度体系的不同层，不新增卡片墙；
- 最近研究表格保持信息密度，行悬停仅显示细边缘与背景提亮。

### 研究过程页

- 顶部任务摘要作为主玻璃面板，进度条使用冰蓝流光；
- 左侧研究轨道增加内缩距离和低对比连线，当前节点以边缘高光和柔和脉冲表达；
- 当前工作、Agent 摘要和事件记录采用不同透明度层级，避免所有区块视觉重量相同；
- 不移动节点、表格列、按钮或数据区域，不影响窄屏响应布局。

## 动效与可访问性

- 背景极光缓慢漂移；信号圆盘低幅旋转；运行中节点与进度条使用有限、非阻塞的脉冲/流光；
- 按钮与可点击行只使用短促的 hover / focus 位移和边缘光，不改变尺寸或文案；
- `prefers-reduced-motion: reduce` 下停用循环动画与过渡；
- 保证文字、表格和状态标签在深色背景上的对比度，焦点状态明确。

## CSS 实施原则

- 在 `styles.css` 的现有应用页规则中收束 token，消除旧浅色规则对新主题的覆盖；
- 复用 `ambient-field`、`glass-surface`、`cursor-spotlight` 等已有装饰节点，不新增交互脚本；
- 仅使用 CSS 的渐变、伪元素、关键帧和现有 DOM；不使用图片、Canvas 或外部资源；
- 保持报告页独立样式边界，避免影响报告正文和离线图表。

## 验收

- 首页与过程页均呈现一致的深色透明金融科技风格；
- 所有表单、按钮、表格、任务状态和“查看报告”链接保留原有行为；
- `prefers-reduced-motion` 可关闭循环动效；
- 静态页面测试继续通过，且 HTML/JS 不因本次样式调整改变功能行为。
