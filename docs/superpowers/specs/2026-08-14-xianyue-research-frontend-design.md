# 弦月研究前端设计规格

## 目标

将现有本地 Web 应用重构为两个原生 HTML/CSS/JavaScript 页面：

1. 研究标的选择页；
2. 研究过程页。

现有独立报告页保持不变。研究完成后，过程页通过“查看报告”按钮打开现有报告页。

设计目标是科技感、设计感和高级感。视觉借鉴现代 AI 产品的克制、留白和精确动效，但不使用 Kimi 的品牌图形、月球光球、渐变语言、字体、布局比例或交互动线。

## 品牌与视觉方向

产品名为“弦月研究”。视觉方向为“黑胶月相”：

- 冷白、近黑和单一钴蓝构成主色系统；
- 使用清晰网格、不对称排版、细线和紧凑的信息层级；
- 核心图形为“弦波切口”：圆弧被锐利斜线切开，同时指向月相、黑胶唱片和价格曲线；
- 摇滚元素来自唱片刻纹、舞台编号、斜切分隔和短促节奏，不使用骷髅、闪电等直白符号；
- 不使用 Dashboard 卡片墙、大面积渐变、玻璃拟态、过度光晕或持续漂浮动画；
- 动效只服务于任务创建、节点推进和状态切换，并支持 `prefers-reduced-motion`。

## 页面一：研究标的选择

桌面端采用不对称左右分栏：

- 左侧呈现品牌标识、产品名称、技术面/基本面研究类型切换和简短的流程说明；
- 右侧呈现标的输入、投资风格、数据截止日期和“开始研究”操作；
- 最近任务位于页面下方，使用紧凑的研究记录带，显示标的、研究类型、状态、当前阶段和创建时间；
- 页面加载后默认聚焦标的输入；
- 切换研究类型时，只改变真实存在的流程说明，不增加后端不支持的参数；
- 提交失败在表单附近就地显示，创建成功后跳转至 `/runs/{run_id}`。

移动端改为单列，顺序为品牌与类型选择、任务参数、最近任务。

## 页面二：研究过程

页面以“研究轨道”为主要结构：

- 顶部显示标的、研究类型、任务状态、总体进度和任务 ID；
- 左侧显示完整节点轨道，区分已完成、执行中、待执行、失败、取消和人工复核；
- 当前节点使用短促脉冲刻度，不使用持续眩目动画；
- 基本面长流程可在轨道区域内部滚动；
- 公司业务研究与行业研究在流程语义允许时以并列分支呈现，后续节点重新汇合；
- 右侧显示当前阶段、运行模式、Checkpoint 状态、Agent 已校验摘要和执行记录；
- 不展示或模拟 Agent 内部思考；
- 失败、人工复核和取消在当前状态区域就地显示；
- 完成后主要操作变为“查看报告”，链接仍为 `/runs/{run_id}/report`。

移动端顺序为状态摘要、可横向浏览的节点轨道、Agent 摘要和执行记录。

## 数据与交互边界

保持现有后端接口和路由不变：

- `POST /api/runs` 创建任务；
- `GET /api/runs` 读取最近任务；
- `GET /api/runs/{run_id}` 读取任务进度和事件；
- `GET /api/runs/{run_id}/executions` 读取已校验 Agent 执行摘要；
- `POST /api/runs/{run_id}/cancel` 取消任务；
- `/runs/{run_id}/report` 打开独立报告页。

过程页继续每两秒轮询，并保持防止请求重叠的现有机制。终态停止轮询。HTML 只负责语义结构，CSS 负责视觉系统，JavaScript 负责数据读取、状态映射和渐进式交互。

## 错误与可访问性

- 网络错误、接口错误和任务错误均显示真实后端信息，不构造诊断结论；
- 表单、按钮、进度条、流程轨道和状态变化保留可访问名称；
- 键盘可完成类型选择、表单提交、历史任务访问、取消和查看报告；
- 颜色不是状态的唯一表达方式，状态同时使用文字和结构差异；
- 移动端不依赖悬停交互；
- 对自动动画提供减少动态效果支持。

## 修改范围

本次主要修改：

- `app/static/index.html`
- `app/static/run.html`
- `app/static/styles.css`
- `app/static/index.js`
- `app/static/run.js`
- `tests/test_pages.py`

不修改研究工作流、任务状态模型、API Schema、独立报告模板和报告生成逻辑。

## 验收标准

- 两个页面在桌面端和移动端均可正常使用；
- 技术面与基本面任务都能创建并进入正确过程轨道；
- 基本面 Business/Industry 节点在视觉上表达并行关系，但不篡改后端真实状态；
- 最近任务、轮询、取消、失败、人工复核、完成和查看报告均保持功能正确；
- 页面无外部 CDN 依赖；
- 页面测试通过，完整 Python 测试、Node 测试和 Bridge 构建不因本次改造回归；
- 最终界面具有独立的“弦月研究”视觉识别，不构成对参考产品的复刻。
